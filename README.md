# Прогноз конечной температуры стального сплава

Модель прогнозирует последнюю измеренную температуру партии стали. Задача проекта — оценить, можно ли использовать прогноз для сравнения сценариев обработки сплава.

[Открыть ноутбук с кодом, графиками и результатами](general_project.ipynb).

## Подход

- Объединил данные SQLite о нагреве, подаче материалов, продувке и замерах температуры. Подготовил выборку из 2 468 партий и 31 входного признака.
- Сравнил Ridge, MLP, случайный лес и градиентный бустинг на пяти блоках кросс-валидации.
- Проверил лучшую модель на отдельной тестовой выборке и разобрал ошибки на крайних температурах.

## Результат

Градиентный бустинг показал **MAE 6,334 °C** при требовании ниже **6,8 °C**. Ошибка на **38% ниже** базового константного прогноза. На крайних температурах точность снижается.

**Стек:** Python, SQLite, pandas, NumPy, Matplotlib, Seaborn, scikit-learn.

## Запуск

Установите зависимости командой `pip install -r requirements.txt`. Поместите базу `ds-plus-final.db` рядом со скриптом и запустите `ipython general_project.py` из корня репозитория.
